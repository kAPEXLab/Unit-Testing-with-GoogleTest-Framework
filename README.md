# GoogleTest Lab Series

This repository contains a focused lab-based tutorial for learning GoogleTest.

## Lab sequence

1. Lab 0: Installation and setup
2. Lab 1: `EXPECT_EQ()`
3. Lab 2: `EXPECT_TRUE()` and `EXPECT_FALSE()`
4. Lab 3: `ASSERT_EQ()` and `ASSERT_NE()`
5. Lab 4: Floating-point testing
6. Lab 5: Test suites
7. Lab 6: Multiple assertions in one test
8. Lab 7: Relational assertions
9. Lab 8: String assertions
10. Lab 9: Fixtures with `TEST_F()`
11. Lab 10: Parameterized tests with `TEST_P()`
12. Lab 11: Safe exit and failure conditions
13. Lab 12: Type-parameterized tests
14. Lab 13: Death tests
15. Lab 14: Custom test messages
16. Lab 15: Test filtering and execution options

## How to use the labs

Open the documentation site in the browser and start from [docs/lab0.md](docs/lab0.md). Each lab builds on the previous one and focuses on a single testing concept.

## Scope

This README is intentionally limited to the lab content and learning flow only.
